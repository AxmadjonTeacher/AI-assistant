# 🦢 SWAN OS — Multilingual Personal AI Operating Assistant

A refined, subtle, and multilingual personal AI assistant for macOS powered by **Gemini 3.1 Flash Live Preview** (`gemini-3.1-flash-live-preview`), featuring global push-to-talk via **`Option + Shift`**, native macOS system execution, and multilingual understanding across **Uzbek, Turkish, English**, and more.

---

## 🌍 Multilingual Intelligence

Swan automatically recognizes the language you speak in real time and replies with matching elegance and language-specific etiquette:

| Spoken Language | Address Style | Example Command | Spoken Response |
| :--- | :--- | :--- | :--- |
| **O'zbekcha (Uzbek)** | *"xo'jayin"* / *"janob"* | *"Safarini och"* | **`"Safari ochilmoqda, xo'jayin."`** |
| **O'zbekcha (Uzbek)** | *"xo'jayin"* | *"Notesga qisqa hikoya yoz"* | **`"Notlar ochilib, qisqa hikoya yozilmoqda, xo'jayin."`** |
| **Türkçe (Turkish)** | *"efendim"* | *"Safariyi aç"* | **`"Safari açılıyor, efendim."`** |
| **Türkçe (Turkish)** | *"efendim"* | *"Notlara kısa bir hikaye yaz"* | **`"Notlar açılıyor ve kısa bir hikaye yazılıyor, efendim."`** |
| **English** | *"sir"* | *"Open Safari"* | **`"Opening Safari, sir."`** |
| **English** | *"sir"* | *"Open notes and write a short story"* | **`"Opening Notes and composing a short story, sir."`** |

You can switch languages seamlessly on any turn without changing any configuration!

## 🚀 Quick Launch

- **macOS Dock:** Click the crystal **Swan** icon in your Dock.
- **Spotlight:** Press **`Cmd + Space`**, type **`Swan`**, and hit **Enter**.
- **Terminal:** Run:
  ```bash
  swan
  ```

---

## 🎙️ How to Use (Push-to-Talk)

1. Hold **`Option + Shift`** anywhere on your Mac.
2. Speak your command in **Uzbek, Turkish, or English**.
3. Release the keys. Swan speaks her confirmation and immediately executes your action!
